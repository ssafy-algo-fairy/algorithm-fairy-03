# 백준 32645: 동까뚱뽭 게임

## 문제 요약
* **목표**: $1$번 정점을 루트로 하는 $N$개의 정점으로 이루어진 트리에서, 각 정점 $i$를 시작점으로 하여 게임을 진행할 때 선공인 '동우'의 승패 여부를 판별합니다. 
* **게임 규칙**:
    * 플레이어는 현재 정점의 **자식 정점** 중 하나로 이동하며 $1$점을 획득합니다. 
    * 말단 노드(Leaf Node)에 도달하여 더 이상 이동할 수 없으면 게임이 종료됩니다. 
    * 최종 점수가 높은 사람이 승리하며, 점수가 같을 경우 후공인 '혁준'이가 승리합니다. 
* **제한 사항**: 정점 개수 $N$ ($1 \le N \le 100,000$), 간선 정보가 주어집니다. 

---

## 사용 로직 및 핵심 알고리즘
* **게임 이론 (Game Theory)**: '승리 상태'와 '패배 상태'의 재귀적 정의를 이용합니다. 
    * **패배 상태 (Losing State)**: 현재 노드가 리프 노드이거나(이동 거리 0으로 동점 상황), 이동 가능한 모든 자식 노드가 상대방의 승리 상태일 때입니다. 
    * **승리 상태 (Winning State)**: 자식 노드 중 하나라도 상대방을 패배 상태로 만들 수 있는 경로가 존재하면 승리 상태가 됩니다. 
* **트리 DP 및 DFS**: 루트(1번 정점)로부터 시작하여 하향식으로 탐색하며 각 정점을 시작점으로 했을 때의 서브트리 내 승패 결과를 `d_win` 배열에 저장합니다. 

---

## 코드 하이라이트
```java
static boolean dfs(int node, int parent) {
    // 말단 노드인 경우 이동이 불가능하므로 선공은 0점, 후공 0점 -> 동점으로 후공 승리(false 반환)
    if (adj[node].size() == 1 && node != parent) {
        d_win[node] = false;
        return false;
    }
    
    boolean ret_val = false;
    for (int c : adj[node]) {
        if (c == parent) continue; // 부모 방향 역행 방지
        
        // 자식 노드 중 하나라도 '패배 상태'가 존재하면 현재 노드는 '승리 상태'
        if (dfs(c, node) == false) {
            ret_val = true;
        }
    }
    
    d_win[node] = ret_val; // 각 노드에서의 게임 결과 저장
    return ret_val;
}
```

---

## 시간 복잡도 분석
* **시간 복잡도**: $O(N)$
    * 트리의 모든 정점과 간선을 한 번씩 방문하는 DFS 탐색을 수행하므로 전체 노드 수 $N$에 비례하는 시간이 소요됩니다. 
* **공간 복잡도**: $O(N)$
    * 인접 리스트(`adj`), 승패 저장 배열(`d_win`), 그리고 최대 $N$ 깊이까지 형성될 수 있는 재귀 호출 스택으로 인해 선형적인 공간을 사용합니다.

* **학습 포인트**:
    * 트리 게임에서 '이동 가능성'과 '점수(거리)'의 홀짝성을 승패 상태로 치환하여 해결하는 논리를 학습했습니다. 
    * 문제에서 정의된 "동점 시 후공 승리" 조건이 결국 리프 노드를 패배 상태(`false`)로 정의하는 것과 동일함을 파악했습니다. 
* **개선 사항**:
    * 본 코드는 문제의 "자식 노드로 이동" 규칙에 따라 루트를 $1$번으로 고정하고 `d_win`을 계산했습니다. 
    * 대규모 데이터 출력 시 성능 최적화를 위해 `BufferedWriter`를 사용한 점이 효율적이었습니다.

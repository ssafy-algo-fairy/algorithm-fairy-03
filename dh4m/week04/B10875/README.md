# [백준 10875] 뱀

## 1. 문제 요약
$2L + 1$ 크기의 격자판(좌표 범위: $-L$ ~ $L$)에서 뱀이 $(0, 0)$ 위치에서 오른쪽(동쪽)을 향해 출발합니다. 뱀은 지정된 시간마다 왼쪽 또는 오른쪽으로 방향을 틀며 이동합니다. 뱀이 **자신의 몸에 부딪히거나 격자판 밖으로 나가는 순간** 게임이 종료됩니다. 게임이 시작된 후 몇 초 후에 종료되는지 구하는 문제입니다.

* **제한 사항**: $L$은 최대 $10^8$로 매우 크며, 방향 전환 횟수 $N$은 최대 1,000입니다.
* **특이 사항**: 격자판의 크기가 매우 크기 때문에 2차원 배열을 이용한 시뮬레이션은 불가능하며, **선분 교차(Line Segment Collision)** 개념을 활용해야 합니다.

---

## 2. 사용 로직 및 핵심 알고리즘
이 풀이는 뱀의 이동 경로를 하나의 **선분(Line Segment)**으로 관리하여 충돌을 판정하는 방식을 채택했습니다.

1.  **선분 객체화**: 뱀이 꺾일 때마다 지금까지 지나온 경로를 `Line` 객체 리스트에 저장합니다.
2.  **충돌 판정 (`collision` 메서드)**:
    * 현재 이동 중인 선분(`now`)이 이전에 생성된 모든 선분(`line[j]`)과 겹치는지 확인합니다.
    * 수평 선분과 수직 선분, 혹은 동일 선상에서의 겹침을 조건문을 통해 분기 처리하여 충돌 시점까지의 거리를 계산합니다.
3.  **경계면 판정 (`isValid`)**:
    * 현재 이동 경로가 격자판의 경계($-L, L$)를 벗어나는지 매 단계 확인합니다.
    * 경계를 벗어난다면 벽에 부딪히기까지의 시간을 계산하여 종료합니다.
4.  **최솟값 탐색**: 여러 선분과 충돌 가능성이 있을 경우, 가장 먼저 부딪히는(거리가 최소인) 시점을 선택합니다.

---

## 3. 코드 하이라이트
현재 선분과 기존 선분들 간의 충돌을 검사하고, 벽 충돌 여부를 판단하는 로직이 핵심입니다.

```java
// 현재 이동 경로(now)와 기존에 지나온 경로(line[j]) 간의 충돌 체크
for (int j = 0; j < i; j++) {
    int col_t = now.collision(line[j]); // 충돌 시 발생하는 시간(거리) 반환
    if (col_t != 0) {
        if (col > col_t) col = col_t; // 가장 먼저 발생하는 충돌 시간 갱신
    }
}

if (col != Integer.MAX_VALUE) {
    t += col; // 충돌 발생 시 현재까지의 시간에 충돌 거리를 더하고 종료
    System.out.println(t);
    return ;
}

// 격자판 경계(벽) 충돌 체크
if (!isValid(dx + d[0] * time[i], dy + d[1] * time[i])) {
    // 방향에 따라 벽까지 남은 거리 + 1(밖으로 나가는 순간) 계산
    if (dir == 0) t += l - dx + 1;
    else if (dir == 1) t += l - dy + 1;
    else if (dir == 2) t += dx + l + 1;
    else if (dir == 3) t += dy + l + 1;
    System.out.println(t);
    return ;
}
```

---

## 4. 시간 복잡도 분석
* **선분 충돌 검사**: 방향 전환 횟수가 $N$일 때, $i$번째 이동에서 최대 $i-1$개의 선분과 충돌 검사를 수행합니다. 이는 산술급수의 합으로 표현되어 $\sum_{i=1}^{N} i = O(N^2)$의 복잡도를 가집니다.
* **전체 복잡도**: $N = 1,000$이므로 $N^2 = 1,000,000$입니다. $L$의 크기에 관계없이 연산 횟수가 일정하므로 제한 시간 내에 충분히 통과 가능합니다 ($O(N^2)$).

## 5. 학습 포인트 및 개선 사항
* **좌표 압축 대신 기하 알고리즘**: $L$이 $10^8$로 매우 클 때, 맵을 직접 구현하는 대신 선분의 좌표 값만을 이용해 충돌을 계산하는 기하학적 접근의 중요성을 학습했습니다.
* **예외 케이스 처리**: 뱀이 자신의 몸에 부딪히는 경우뿐만 아니라, 마지막 명령 수행 후에도 벽에 부딪힐 때까지 계속 직진해야 하는 예외 상황 처리가 필수적입니다.
* **최적화 제안**: 현재는 수평/수직 조건을 `if-else`로 복잡하게 분기 처리하고 있으나, 두 선분의 $x$범위와 $y$범위가 교차하는지 확인하는 일반적인 선분 교차 공식(CCW 등)을 응용하면 코드를 더욱 간결하게 개선할 수 있습니다.

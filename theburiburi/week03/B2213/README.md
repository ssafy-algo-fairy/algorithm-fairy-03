# [Gold I] 트리의 독립집합 - 2213

[문제 링크](https://www.acmicpc.net/problem/2213)

## 💡 풀이 접근 및 핵심 아이디어

이 문제는 트리의 구조를 띠는 그래프에서 **가장 가중치의 합이 큰 독립집합(서로 인접하지 않은 노드들의 집합)**을 찾고, 그 집합에 속한 노드들을 오름차순으로 출력하는 문제입니다.

### 1. 트리 DP (상태 정의)
트리의 특성상 부모 노드의 포함 여부가 자식 노드들의 포함 여부에 직접적인 영향을 미칩니다. 이를 해결하기 위해 2차원 DP 배열을 선언합니다.
* `dp[now][0]`: 현재 노드(`now`)를 **포함하지 않았을 때**, 해당 서브 트리에서 얻을 수 있는 최대 가중치 합
* `dp[now][1]`: 현재 노드(`now`)를 **포함했을 때**, 해당 서브 트리에서 얻을 수 있는 최대 가중치 합

### 2. 점화식 도출 (DFS 탐색)
트리의 단말 노드(Leaf Node)부터 루트 노드까지 상향식(Bottom-up)으로 DP 값을 채워나갑니다.
* **현재 노드를 포함하는 경우:** 인접한 자식 노드는 절대 포함할 수 없으므로, 자식 노드를 포함하지 않은 최댓값(`dp[next][0]`)들을 더해줍니다.
* **현재 노드를 포함하지 않는 경우:** 자식 노드는 포함할 수도 있고, 안 할 수도 있습니다. 두 경우 중 더 큰 값(`max(dp[next][0], dp[next][1])`)을 더해줍니다.

### 3. 경로 역추적 (Path Tracking)
최대 가중치를 구한 뒤에는 실제로 어떤 노드들이 선택되었는지 찾아야 합니다. 루트 노드에서부터 하향식(Top-down)으로 내려가며 DP 테이블의 값을 비교해 선택된 노드를 리스트에 담아줍니다.

---

## 🔑 핵심 코드 설명

```java
// 1. 트리 DP 상태 갱신 (DFS)
static void dfs(int now, int parent) {
    dp[now][0] = 0;
    dp[now][1] = value[now]; // 포함할 경우 자신의 가중치로 초기화

    for (int next : adj[now]) {
        if (next == parent) continue; // 양방향 간선이므로 부모로 되돌아가는 것 방지
        dfs(next, now);

        // 현재 노드를 포함하지 않는다면, 자식을 포함하는 것과 안 하는 것 중 최댓값 선택
        dp[now][0] += Math.max(dp[next][0], dp[next][1]);
        // 현재 노드를 포함한다면, 자식은 무조건 포함하지 않아야 함
        dp[now][1] += dp[next][0];
    }
}

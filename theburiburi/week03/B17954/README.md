# [Gold] 투튜브 - 17954

[문제 링크](https://www.acmicpc.net/problem/17954)

## 💡 풀이 접근 및 핵심 아이디어

이 문제는 1부터 2N까지의 사과를 두 개의 튜브(크기 N)에 나누어 담은 뒤, 양끝에서 하나씩 꺼내면서 누적되는 비용(무게)을 구하는 문제입니다. 핵심은 **"어떻게 배치해야 최적의 결과를 얻을 수 있는가?"**를 파악하는 것입니다.

### 1. 양끝에 '가장 무거운 사과'를 배치 (Blocker 역할)
* 꺼낼 때는 항상 **현재 노출된 양끝의 4개 사과 중 가장 가벼운(작은) 것**을 먼저 꺼내게 됩니다.
* 따라서 가장 무거운 사과들(`2N, 2N-1, 2N-2, 2N-3`)을 튜브의 양쪽 끝에 배치하여, 내부에 있는 가벼운 사과들이 일찍 꺼내지지 않도록 막아주는 일종의 '방패' 역할을 하게 만듭니다.

### 2. 가벼운 사과들은 내부에 배치
* 가장 무거운 `2N`과 `2N-1`은 두 번째 튜브(`apple2`)의 양끝에 배치하여 가장 마지막까지 남도록 유도합니다.
* 그 다음으로 무거운 `2N-2`와 `2N-3`은 첫 번째 튜브(`apple1`)의 양끝에 배치합니다.
* 이렇게 하면 시뮬레이션 시 `apple1`의 끝에 있는 `2N-3`과 `2N-2`가 먼저 빠지면서 내부의 가장 작은 사과들이 노출되고, 의도한 순서대로 사과를 꺼낼 수 있습니다.

### 3. 덱(Deque)을 이용한 시뮬레이션
* 양쪽 끝에서 데이터를 확인하고 뽑아내야 하므로, 각 튜브를 `ArrayDeque`로 만들어 양끝 값(`peekFirst`, `peekLast`)을 비교하며 최소값을 찾는 방식으로 정답 비용을 계산합니다.

## 🔑 핵심 코드 설명

```java
// 1. 가장 무거운 사과 4개를 양끝에 배치
apple1[0] = 2 * N - 2;
apple1[N - 1] = 2 * N - 3;
apple2[0] = 2 * N;
apple2[N - 1] = 2 * N - 1;

// 2. 나머지 작은 사과들을 내부에 순서대로 채워 넣기
int num = 1;
for (int i = 1; i < N - 1; i++) apple2[i] = num++;
for (int i = 1; i < N - 1; i++) apple1[i] = num++;

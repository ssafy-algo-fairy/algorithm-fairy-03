### 💡 접근 방식

> 2×N 배열에 1~2N을 배치해서 점수의 합을 최대화하는 문제입니다.  
> 큰 수를 앞쪽 열에 배치할수록 이후 열에서 계속 더해지므로 최대한 앞에 배치해야 합니다.  
> 배치 식을 직접 생각하지 못해서 찾아봤습니다.

---

### 🔹 1단계 – 점수 계산 방식

```
열 1의 합 × 1
열 2의 합 × 2  (이전 열까지 누적합 제외)
...
```

`size`를 전체 합에서 하나씩 빼가면서 각 열의 가중치를 곱해 누적

```java
long size = ((2L * N) * ((2L * N) + 1)) / 2;  // 1~2N 합

for(
int i = 0;
i <=N -1;i++){
size -=arr[0][i];
answer +=(i +1)*size;
}
```

---

### 🔹 2단계 – 배치 전략

큰 수를 앞에, 작은 수를 뒤에 배치하는 게 핵심

```
2N-1, 2N  →  1열 (가장 큰 수 두 개를 맨 앞에)
2N-2       →  2열
...
```

구체적으로

```
1행: [2N-3, ..중간 작은 수.., 2N-2]
2행: [2N-1, ..중간 작은 수.., 2N  ]
```

---

### 🔹 3단계 – 배치 공식

```java
arr[0][0]=2*N -3;
arr[0][N -1]=arr[0][0]+1;   // 2N-2

arr[1][0]=2*N -1;
arr[1][N -1]=arr[1][0]+1;   // 2N

// 중간 칸은 작은 수들로 채우기
        for(
int j = 1;
j <=N -2;j++){
arr[i][j]=arr[0][0]-((i *(N -2))+j);
        }
```

양 끝에 큰 수를 배치하고 중간을 작은 수로 채워서  
앞쪽 열의 합이 최대가 되도록 구성
